Laravel Homestead is the virtual machine I use for local Laravel development.
It provides a consistent development environment with PHP, Composer, MySQL,
Nginx, Redis, and other tools already configured.

## Prerequisites

Before installing Homestead, install:

- VirtualBox
- Vagrant
- Git

## Install Homestead

Clone the Homestead repository.

```bash
git clone https://github.com/laravel/homestead.git ~/Homestead
```

Move into the directory.

```bash
cd ~/Homestead
```

Initialize Homestead.

```bash
bash init.sh
```

This creates your `Homestead.yaml` configuration file.

## Configure Homestead

The main configuration file is:

```text
~/Homestead/Homestead.yaml
```

Common settings include:

```yaml
folders:
  - map: C:\Codes
    to: /home/vagrant/Codes

sites:
  - map: my-app.test
    to: /home/vagrant/Codes/my-app/public

databases:
  - my_app
```

## Start the Virtual Machine

```bash
vagrant up
```

Or using my Bash alias:

```bash
hm-start
```

## SSH into Homestead

```bash
vagrant ssh
```

Or:

```bash
hm-ssh
```

## Stop Homestead

```bash
vagrant halt
```

Or:

```bash
hm-stop
```

## Reload Homestead

After changing `Homestead.yaml`:

```bash
vagrant reload --provision
```

Or:

```bash
hm-reload
```

## Laravel Commands

Once inside the VM:

```bash
php artisan serve
```

```bash
php artisan migrate
```

```bash
composer install
```

```bash
php artisan optimize:clear
```

## Access phpMyAdmin

If you have phpMyAdmin installed in Homestead:

```text
http://phpmyadmin.test
```

or your configured local domain.

## Useful Commands

Check VM status.

```bash
vagrant status
```

Suspend the VM.

```bash
vagrant suspend
```

Resume the VM.

```bash
vagrant resume
```

Destroy the VM.

```bash
vagrant destroy
```

::tip
Treat Homestead like a dedicated development computer. Keep your projects on
the shared folder, do your Laravel work inside the VM, and let Vagrant handle
the environment. It saves you from the timeless tradition of "works on my
machine" becoming "why doesn't it work on anyone else's machine?"
::
