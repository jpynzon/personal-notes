Your `.bashrc` runs on every interactive shell. A few well-chosen lines pay for
themselves within a day.

## Better history

```bash [~/.bashrc]
HISTSIZE=100000
HISTFILESIZE=200000
HISTCONTROL=ignoreboth:erasedups   # drop duplicates and space-prefixed commands
shopt -s histappend                # append instead of overwriting
PROMPT_COMMAND='history -a'        # write history immediately, not on exit
```

## Aliases I can't live without

```bash [~/.bashrc]
alias ll='ls -lah'
alias ..='cd ..'
alias ...='cd ../..'
alias gs='git status -sb'
alias gl='git log --oneline --graph --decorate -20'
alias serve='python3 -m http.server'
alias reload='source ~/.bashrc'
```

## Handy functions

```bash [~/.bashrc]
# make a directory and cd into it
mkcd() { mkdir -p "$1" && cd "$1"; }

# extract almost any archive
extract() {
  case "$1" in
    *.tar.gz|*.tgz) tar xzf "$1" ;;
    *.tar.bz2)      tar xjf "$1" ;;
    *.zip)          unzip "$1" ;;
    *.gz)           gunzip "$1" ;;
    *) echo "Don't know how to extract '$1'" ;;
  esac
}
```

## A readable git-aware prompt

```bash [~/.bashrc]
parse_git_branch() {
  git branch 2>/dev/null | sed -n 's/^\* \(.*\)/ (\1)/p'
}
PS1='\[\e[32m\]\u@\h\[\e[0m\]:\[\e[34m\]\w\[\e[33m\]$(parse_git_branch)\[\e[0m\]\$ '
```

::note
Keep machine-specific settings (like `PATH` additions for a work laptop) in a
separate `~/.bashrc.local` and source it at the end. Your main dotfiles stay
portable across machines.
::

```bash [~/.bashrc]
[ -f ~/.bashrc.local ] && source ~/.bashrc.local
```
