## Safe script header

Start every non-trivial script with strict mode — it turns silent failures into
loud ones.

```bash [script.sh]
#!/usr/bin/env bash
set -euo pipefail
IFS=$'\n\t'
```

- `-e` exit on any error
- `-u` error on undefined variables
- `-o pipefail` a pipeline fails if any stage fails

## Loop over files safely

```bash
for file in ./logs/*.log; do
  [ -e "$file" ] || continue   # handle the "no matches" case
  echo "Processing $file"
done
```

## Parse flags with getopts

```bash
while getopts ":n:v" opt; do
  case "$opt" in
    n) name="$OPTARG" ;;
    v) verbose=1 ;;
    *) echo "usage: $0 [-n name] [-v]"; exit 1 ;;
  esac
done
```

## Clean up on exit

```bash
tmp="$(mktemp)"
trap 'rm -f "$tmp"' EXIT
```

## Heredoc for multi-line output

```bash
cat <<EOF > config.yml
name: $name
env: production
EOF
```

::tip
Quote your variables — `"$var"` not `$var`. Unquoted expansion breaks on spaces
and is the single most common shell scripting bug.
::
