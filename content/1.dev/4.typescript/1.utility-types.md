TypeScript ships transformations that derive new types from existing ones. Learn
these and you'll stop duplicating shapes.

## The workhorses

```ts
interface User {
  id: number
  name: string
  email: string
}

Partial<User>            // all properties optional — great for updates
Required<User>           // all properties required
Readonly<User>           // all properties immutable
Pick<User, 'id' | 'name'>  // subset: { id, name }
Omit<User, 'email'>        // everything except email
```

## Mapping keys to values

```ts
type Role = 'admin' | 'editor' | 'viewer'

const permissions: Record<Role, string[]> = {
  admin: ['read', 'write', 'delete'],
  editor: ['read', 'write'],
  viewer: ['read']
}
```

## Deriving from functions and promises

```ts
function createUser() {
  return { id: 1, name: 'Ada' }
}

type NewUser = ReturnType<typeof createUser>   // { id: number; name: string }
type Resolved = Awaited<Promise<string>>       // string
```

## Compose them

::tip
Utility types nest. `Partial<Pick<User, 'name' | 'email'>>` is a perfectly
readable "optional name and email" type for a patch endpoint.
::

```ts
type UserPatch = Partial<Omit<User, 'id'>>   // update anything but the id
```
