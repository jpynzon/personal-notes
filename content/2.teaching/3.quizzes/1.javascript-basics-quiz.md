Ten-minute check for understanding after the first two JavaScript sessions. Use
it as a warm-up or an exit ticket.

## Questions

1. What is the difference between `let` and `const`?
2. What does `typeof null` return? Is that a bug or a feature?
3. Predict the output: `console.log(1 + '1')`
4. Predict the output: `console.log('5' - 2)`
5. Which values are "falsy" in JavaScript? Name at least four.
6. What's the difference between `==` and `===`?
7. Write a `const` that holds your name, then log a greeting using it.

## Answer key

::collapsible{name="the answers"}

1. `let` can be reassigned; `const` cannot be reassigned (though objects it holds
   can still be mutated).
2. `"object"` — a long-standing quirk kept for backwards compatibility. Treat it
   as a wart, not a rule.
3. `"11"` — the number is coerced to a string and concatenated.
4. `3` — `-` has no string meaning, so `'5'` is coerced to a number.
5. `false`, `0`, `''` (empty string), `null`, `undefined`, `NaN`.
6. `==` compares after type coercion; `===` compares value **and** type. Prefer
   `===`.
7. Example: `const name = 'Ada'; console.log(\`Hello, ${name}\`)`

::

::tip
Question 3 vs 4 is the money moment — the `+` operator is overloaded for strings,
every other arithmetic operator is not. Let students argue about it before you
reveal the key.
::
