Copy-pasting from ChatGPT breaks down fast: you lose track of which file a snippet
belongs to, and the AI never sees the rest of your project. OpenCode runs in your
terminal **inside your project folder**, so it reads your real files and writes code
straight into them.

This pairs with the [Prompt Flow](/teaching/apps-dev/ai-prompts/basic-prompting) —
same discipline, better tool.

## Prerequisites

::steps{level="3"}

### Install Node.js

Download it from [nodejs.org/en/download/current](https://nodejs.org/en/download/current).

Choose the **Windows Installer (.msi)**.

![The Node.js download page with the Windows Installer (.msi) option highlighted](https://res.cloudinary.com/du6rliaeg/image/upload/v1784941589/node-install_vavvgm.png)

### Verify the installation

Open **Command Prompt** (CMD) and run:

```bash
node -v
```

It should print a version number such as `v24.12.0` — the exact version depends on
what you installed. If you get "command not found", close and reopen CMD first;
the installer only updates the PATH for new terminal windows.

::

## Installing OpenCode

::steps{level="3"}

### Install the package globally

In CMD or Git Bash:

```bash
npm install -g opencode-ai
```

### Start OpenCode

If it didn't open automatically after installing, run:

```bash
opencode
```

### Get an API key

Open [opencode.ai/zen](https://opencode.ai/zen) in your browser, click
**Get started with Zen**, and register or log in.

After registering, click **Copy Key**.

![The OpenCode Zen dashboard showing the API key with a Copy Key button](https://res.cloudinary.com/du6rliaeg/image/upload/v1784941588/zen-api-key_lp9gxr.png)

::warning
An API key is a password. Don't paste it into a chat, a screenshot, or a file you
commit to Git.
::

### Connect the key

Back in the terminal where OpenCode is running, type `/connect`, choose
**OpenCode Zen**, then paste the key and press :kbd{value="enter"}.

![The OpenCode /connect command with OpenCode Zen selected as the provider](https://res.cloudinary.com/du6rliaeg/image/upload/v1784941589/connect-key-opencode_q8rmrd.png)

### Pick a model

Type `/models` and choose a free one — for example **DeepSeek V4 Flash Free**.

![The OpenCode model picker listing available models including free options](https://res.cloudinary.com/du6rliaeg/image/upload/v1784941588/models_ol8qjn.png)

### Test it

Send any message to confirm the connection works before you start on real code.

::

## Using it on a project

::steps{level="3"}

### Open a terminal in your project folder

Right-click inside the folder and choose **Open in Terminal** or
**Open Git Bash here**.

![Windows right-click context menu showing the Open in Terminal option](https://res.cloudinary.com/du6rliaeg/image/upload/v1784941588/open-cmd-in-project_pgr0ca.png)

::note
This step is the whole point. OpenCode only sees the folder you launched it from —
launch it from the wrong place and it writes files in the wrong place.
::

### Run OpenCode

```bash
opencode
```

![OpenCode running inside a project folder in the terminal](https://res.cloudinary.com/du6rliaeg/image/upload/v1784941588/type-open-code-in-project_l1sadw.png)

### Switch between Plan and Build mode

Press :kbd{value="shift"} :kbd{value="tab"} to toggle.

- **Plan mode** — the AI proposes what it will do without touching your files.
- **Build mode** — the AI actually edits files.

![OpenCode showing Plan mode after pressing Shift + Tab](https://res.cloudinary.com/du6rliaeg/image/upload/v1784941588/shift-tab-plan-mode_g87mdp.png)

### Start building

Every generated file lands inside the folder you opened the terminal in — no
copy-pasting, no guessing which file a snippet belonged to.

::

## Habits worth keeping

::tip
Plan before you build. Read what it wrote. Commit often so you can undo a bad
generation with Git instead of by hand.

The tool changed; the responsibility didn't. You still have to be able to explain
every line it produces.
::
